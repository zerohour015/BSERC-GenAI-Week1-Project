DSA at a Glance

Insertion sort · Merge sort · Binary search trees

Insertion sort

1. Keep the processed prefix sorted.
2. Take the next key.
3. Move it to its correct position.
4. Repeat until the array is sorted.

Worst case in MIT example: Θ(n²)

Reverse-ordered input causes many comparisons and swaps. Binary insertion reduces comparisons, but shifts remain.

Merge sort

1. Divide the array into two halves.
2. Recursively sort each half.
3. Merge the sorted halves.

Total time: Θ(n log n)

T(n) = 2T(n/2) + Θ(n)

One merge processes n elements in Θ(n) time; there are logarithmically many recursion levels.

BST ordering rule

Left keys ≤ node key ≤ right keys

To search, compare at the current node and follow a left or right pointer. To find the minimum, keep following left pointers.

BST operations and height

  • Insert: follow child pointers to the insertion point.
  • Find: follow a search path until found or NIL.
  • Find minimum: go left until no left child remains.
  • Next larger: use right-subtree minimum or move up to an ancestor.

Core operations: O(h)

h is tree height. Sorted insertion can produce a chain-like tree, so logarithmic time requires a balanced shape.
