# Project 1 — NotebookLM kit contents

This folder contains the prepared materials for the source-grounded DSA notebook:

- `Project1_NotebookLM_Setup.md` — notebook creation, chat configuration, prompts and Studio checklist.
- `Project1_Source_Register_and_Setup.md` — seven suggested MIT sources across PDFs, YouTube and websites.
- `DSA_Study_Guide.md` — source-grounded summaries with links to lecture notes.
- `DSA_Quiz_and_Answer_Key.md` — 12 revision questions and answer key.
- `DSA_Flashcards.csv` — 16 flashcards with source references.
- `DSA_Mind_Map.md` — Mermaid concept map source.
- `DSA_Infographic.html` — responsive, printable one-page visual.
- `DSA_Slide_Deck.html` — eight-slide interactive browser presentation.
- `Audio_Overview_Script.md` — narration draft; not a generated audio file.
- `Video_Overview_Storyboard.md` — storyboard; not a generated video.
- `Project1_Verification_Log.md` — citation checks and NotebookLM feature tests to complete in your account.

**Important:** These are prepared companion assets, not NotebookLM-generated Studio outputs. Create the notebook, import the sources, generate its Audio/Video Overview, Mind Map, quiz, flashcards, infographic and slide deck in NotebookLM where available, verify at least two citations, then share the notebook link.
