## Configure chat
Use this as your chat goal/style:
> You are my DSA exam revision partner. Answer only from the sources in this notebook. Cite the source passages for factual claims. If the sources do not contain the answer, clearly say “The provided sources do not establish this.” Do not silently fill gaps from general knowledge. Explain concepts at BTech second-year level, use concise step-by-step examples, and distinguish the source's statements from any inference.

## Test prompts to run in NotebookLM
1. “Explain the time complexity of merge sort using only the provided sources. Cite the supporting source.”
2. “Compare merge sort and quick sort. Make a table only for properties supported by my sources and cite each row.”
3. “What conditions are required for binary search? Cite the source.”
4. “Give me one exam-style question about sorting and answer it with citations.”
5. “What is the difference between Big-O, Big-Ω and Big-Θ according to my sources?”
6. Off-topic test: “What is the capital of France?” Check whether the notebook makes clear that the sources do not answer it, instead of pretending the notebook sources support an answer.
7. Source-on/off test: ask one question with all sources enabled, then restrict sources if NotebookLM provides that control and compare the answer.
8. Check at least two answer citations by opening the source passage and confirming it actually supports the claim.
